# Робот-наставник — MVP кабинета

Торговый робот в аренду, который торгует, объясняет каждое решение и учит пользователя.
Это демо интерфейса: статичная страница без сервера.

**Посмотреть:** https://pizko.github.io/robot-nastavnik/

## Что внутри

- **Лента.** Каждая сделка робота — карточка: что купил, почему (голоса техники, новостей и ML с весами), какие проверки прошли, портфель до и после. Отказы тоже объяснены: «хотел купить, но не стал, потому что…».
- **Страховка.** Лимиты простыми словами, ползунки в разрешённых рамках, кнопка «Стоп-всё», режимы доверия (наблюдение / автопилот / учебный).
- **Учёба.** «Дуэль»: реальная ситуация из истории, ваше решение против решения робота. Словарь терминов, подсказки по всему кабинету.
- **Результаты.** Проверка стратегии на истории 2021–2026 с комиссиями и проскальзыванием, сравнение с индексом МосБиржи.

## Данные

`data/data.json` — обезличенная выгрузка:
- карточки решений с paper-счёта робота (сделки по настоящим ценам без настоящих денег);
- проверка стратегии на дневных свечах 40 акций МосБиржи.

Ключей, номеров счетов и кода стратегии в репозитории нет.

Это не инвестиционная рекомендация, доходность не обещается.
